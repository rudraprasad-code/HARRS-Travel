
# HARRS Travel – Travel Agency Management System

## About the Project
HARRS Travel is a desktop-based Travel Agency Management System developed using Java and MySQL. The application helps manage travel agency operations, including customer details, vehicle information, member records, and travel bookings. It provides a user-friendly interface and stores information in a MySQL database for efficient data management.

## Features
- Customer Management
- Vehicle Management
- Vehicle Search and Details
- Member Management
- Travel Booking Management
- Admin Management
- Customer Support Information
- MySQL Database Integration

## Technologies Used
- **Programming Language:** Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Application Type:** Desktop-Based Application

## Modules
1. **Admin Module:** Manages system records and operations.
2. **Vehicle Module:** Adds, updates, deletes, and searches vehicle information.
3. **Member Module:** Manages member details.
4. **Customer Module:** Maintains customer information.
5. **Booking Module:** Manages travel booking records.
6. **Customer Support Module:** Provides contact and support information.

## Requirements
- Java JDK
- MySQL Server
- MySQL JDBC Driver
- Java IDE such as Eclipse, IntelliJ IDEA, or NetBeans

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/rudraprasad-code/HARRS-Travel.git
```

### 2. Open the Project
Open the project in your preferred Java IDE.

### 3. Configure MySQL
- Start your MySQL server.
- Create the required database.
- Import or execute the project's SQL file, if provided.
- Update the database connection URL, username, and password in the Java source code.

### 4. Configure JDBC
Ensure the MySQL JDBC driver is added to the project's classpath.

### 5. Run the Application
Run the project's main Java class from your IDE.
